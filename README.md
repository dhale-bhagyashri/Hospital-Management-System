
# Hospital Management System

## About the Project
This is a simple Hospital Management System
developed using Core Java.

## Features
- Add patient details
- View all patient records
- Search patients by ID
- Exit the application

## Technologies Used
- Core Java
- Object-Oriented Programming
- ArrayList
- Scanner Class

## How to Run
1. Install Java JDK.
2. Download HospitalManagementSystem.java.
3. Open the file in Eclipse or any Java IDE.
4. Run the HospitalManagementSystem class.
5. Select an option from the menu.

## Concepts Used
- Classes and Objects
- Constructors
- Methods
- ArrayList
- Loops
- Conditional Statements

## Note
Patient records are stored temporarily in an ArrayList.
Records will be lost when the program terminates.
